# 阿紫幸存者 · Azi Survivor

一款类《土豆兄弟》(Brotato) 玩法的 2D 割草生存游戏（玩法借鉴 + 全部美术换皮重绘）。
**主角为紫发绿卫衣少年「阿紫」**，全部美术资源由代码逐像素手绘（Canvas 2D 矢量绘制 + 手写 SVG 图标），
**全部音效由 WebAudio 实时合成**，零外部资源文件，双击即玩。

## 如何运行

直接双击打开 `index.html`（推荐 Chrome / Edge / Firefox），无需服务器、无需安装任何依赖。

```
potato-survivor/
├── index.html      页面框架 + 全部界面样式（含键位图）
├── js/
│   ├── icons.js    手写 SVG 图标（武器/道具/升级/UI）
│   ├── data.js     数值配置（角色/武器/道具/升级/敌人）
│   ├── audio.js    程序化音效合成器
│   ├── art.js      全部 Canvas 手绘美术（含主角）
│   └── game.js     核心引擎（战斗/波次/商店/升级）
└── README.md
```

## 主菜单

Brotato 式布局：深色氛围场景（怪物剪影 + 聚光灯）中央站着持械的主角，左右两侧是菜单。

- **左列**：开始游戏 / 最佳战绩 / 图鉴 / 设置 / 退出
- **右列**：新消息（更新日志）/ 版本号
- **图鉴**：4 个标签页，收录全部 9 把武器、12 件道具、4 种敌人的属性与描述，以及玩法说明
- **设置**：音效 / 屏幕震动 / 伤害数字，自动保存在本机浏览器
- **最佳战绩**：读取本机存档的最高波次、击杀、材料与存活时间

## 操作

| 按键 | 功能 |
|---|---|
| `W A S D` / 方向键 | 移动（武器全自动攻击） |
| `H` | 键位图开关（默认展开，仅键鼠设备显示） |
| `P` | 暂停 |
| `M` | 音效开关（会弹出提示） |
| `O` | 调试入口（需密码 `7891`，见下文） |

- **属性面板只在波间显示**：战斗界面不再占屏，属性表固定在**商店与升级界面右侧**（含 13 项数值），手机端同样在波间界面查看。
- **键位图只在键鼠设备显示**：手机/平板等触屏设备（`hover:none` + `pointer:coarse`）一律不显示，与 UA 判断无关；桌面端战斗时左上角展示，`H` 可开关。
- **手机端**：移动用屏幕左半区拖拽虚拟摇杆。

波间界面（商店 / 升级）按参考图比例设计：面板宽 1180px（约占 1920 宽屏的 61%），卡片自适应等分（4 张时约 206px/张，图标 58px），升级固定给 **4 个选项**，右侧常驻属性栏。

**手机端波间界面**（≤960px 重排为单列）：

- 升级界面：4 张强化卡排成 **2×2**，下方紧跟属性栏，小屏（≤560px）属性自动转 **三列** —— 整屏显示完，不用滚动
- 商店界面：商品 **2 列**，三个操作按钮一行，背包与属性栏依次在下，属性同样三列
- 关键修复：单列布局时 `align-items:stretch`（原来 `flex-start` 会让主列收缩到 177px，卡片被迫排成一长列，把属性栏顶出屏幕）

## 战斗表现

- **远程武器固定在左右两侧悬停**：持有的每把枪/法杖按奇偶分配到身体左/右两侧的固定槽位（同侧多把纵向排开），只做轻微上下浮动、**不绕圈**；各自转向瞄准最近的敌人开火，并优先攻击自己这一侧的敌人
- **开火后坐力**：射击瞬间武器沿枪口反方向后退 + 垂直方向小幅抖动，同时带枪口火花
- **枪口与子弹严格同向**：漂浮武器每帧只计算一次「位置 + 目标 + 朝向」，开火直接复用这份结果（实测枪口与子弹夹角偏差 < 0.2°），不会再出现枪口朝左子弹朝右
- **高命中率**：子弹采用「线段扫掠」碰撞（不会因高速穿透小怪而漏判）+ 按敌人移速计算提前量，实测手枪/冲锋枪/霰弹/魔杖/回旋镖命中率均为 100%
- **枪械后坐力**：开火瞬间武器沿瞄准反方向后退回弹
- **近战挥砍：提前起手，落刀命中**：刀剑/铁锤有完整的「举起 → 劈下 → 收招」三段动作（总 0.36s），伤害在**刀锋落下那一刻**（第 216ms）才结算，不是一按就扣血
- **预判出手**：怪物在刀落时会进入攻击范围就提前起手（按怪物移动速度算提前量），怪物走到面前的瞬间刀刚好劈到；长矛是直线突刺、铁锤是高举猛砸
- 整个手臂会转向目标方向，刀锋沿瞄准方向劈下，命中带刀光弧 / 冲击环与屏幕震动
- **材料吸入**：宝石被吸取时带拖尾火花，入体瞬间绿色光环 + 火花 + "+N" 飘字

深色玻璃拟态 + 金色点缀的原创 UI（非照搬他人）：HUD 药丸式信息条、稀有度配色的商店卡牌、键帽式键位图、幸运转盘、居中提示弹窗。物品/武器分 3 档稀有度（普通/精良/稀有），商店边框与 HUD 槽位按稀有度着色。

## 玩法

- **目标**：在竞技场中活过 **20 波** 敌人袭击即胜利，生命归零则失败。
- **战斗**：武器自动攻击最近的敌人，你只管走位。击杀怪物掉落绿色材料（货币）和经验。
- **刷怪节奏**：场上少于 5 只时补怪速度翻倍、一次刷 2 只且更靠近玩家；**清场后约 0.1 秒立刻补怪**，不会出现空场干等。
- **波间商店**：每波结束后购买武器/道具，可刷新（材料累积加价）、可治疗、可出售（返还 50%）。
- **升级三选一**：击杀攒经验升级，从 14 种强化中选一项，越战越强。
- **精英怪**：第 5/10/15/20 波出现戴皇冠的精英，击败掉落宝箱——**触碰宝箱打开幸运转盘**！

## 精英宝箱 · 幸运转盘

击败精英后触碰宝箱即可转盘抽奖，**越稀有的奖品概率越低**：

**扇区大小 = 概率**：转盘不是等分的，扇区角度按权重划分（30% 的扇区 108°，3% 的只有 10.8°），一眼就能看出每个奖品的中奖概率。指针在正上方、尖端朝下指向盘面。

## 想调数值？

所有平衡性数据都集中在 `js/data.js`，改完刷新页面即生效：

- 武器手感 → `WEAPONS`（`dmg` 伤害、`cd` 冷却、`range` 距离）
- 敌人强度 → `ENEMIES` + 底部四个 `wave*` 曲线函数
- 波次时长 → `waveDuration(w)`
- 商店物价 → 各条目 `price` 字段
- 角色配色/强度 → `CHARS` 的 `colors` / `mods`

## 技术说明

- **渲染**：单 `<canvas>`，离屏缓存竞技场背景（有机草地纹理 + 暗角），相机跟随 + 屏幕震动 + 受击红晕 + 屏外敌人方向箭头
- **美术**：主角（眨眼/坏笑/行走摆动/4 套服装配件/手持近战武器挥砍动画）、敌人（史莱姆果冻形变/蝙蝠扑翼/石头人裂纹）、刀光/冲击环/爆炸/升级光柱等全套特效，全部为程序化矢量绘制
- **音效**：振荡器 + 噪声缓冲实时合成 20 种音效，无音频文件
- **性能**：1366×768 下 40+ 敌人同屏稳定 60 FPS（HUD 已移除 backdrop-filter 以避免合成层打爆帧率）
- **高清适配**：转盘画布按 devicePixelRatio 放大位图（DPR=2 时为 664×664 位图 / 332px 显示），高分屏文字锐利不糊
